Privacy policy — ReTold Studio

Last updated: 9 October 2026

ReTold Studio is a private publishing tool used only by the owner of the ReTold YouTube channel to upload and manage the channel's own videos. It is not offered to the public and has no other users.

What the app accesses

When the channel owner signs in with Google, the app asks for permission to use the YouTube Data API and the YouTube Analytics API in order to:

  • upload ReTold's videos, thumbnails and captions, and set their title, description, schedule and privacy;
  • read the status of those uploads;
  • read ReTold's own channel analytics (views, watch time, retention) to improve future videos.

How data is used and stored

  • The sign-in token is stored only on the channel owner's own computer. It is never sent to any other server.
  • Analytics are stored locally on the same computer and used only to plan ReTold's own videos.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • The app does not access any other person's account or data.

ReTold Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also follows the YouTube Terms of Service; see the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.

Contact

Questions about this policy: contact ReTold through the channel's About page.
